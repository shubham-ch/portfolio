# Personal Portfolio Website

A personal portfolio website designed to showcase my background, technical skills, projects, experience, and other professional information.

The website serves as a central place to present my work and provide an overview of my experience as a software developer.

## Overview

This portfolio was built as a responsive web application with a focus on clean design, simple navigation, and presenting professional information in an accessible way.

It includes dedicated sections for personal information, skills, projects, experience, and contact information.

## Features

* Personal introduction and profile
* Professional experience
* Technical skills
* Project showcase
* Contact section
* Responsive web design
* Structured navigation between portfolio sections
* Custom styling and visual assets

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/shubham-ch/portfolio.git
cd portfolio
```

### Run Locally

Since the project is built using HTML, CSS, and JavaScript, it can be opened directly in a browser.

Open:

```text
index.html
```

Alternatively, you can use a local development server such as the **VS Code Live Server** extension.
